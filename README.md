## What is SkillBridge?

A hyperlocal skill marketplace that connects skilled workers (plumbers, electricians, tailors, repair technicians and more) directly with customers in Hubli-Dharwad — no middlemen, no commission, no app install needed.

Workers create a **Skill Card** in 2 minutes, upload work proof, get verified by a local admin, and start getting hired directly via WhatsApp or call.

---

## The Problem We Solved

In cities like Hubli-Dharwad, thousands of skilled workers struggle to find consistent work. Big platforms don't cover Tier-2 cities. Middlemen take large cuts. Word-of-mouth only goes so far.

**Workers lack a digital identity. Customers lack trust signals.**

SkillBridge fixes both.

---

## Features

**For Workers**
- Create a skill card — no resume needed
- Upload work proof (photo / video / document)
- Missed call registration for workers without smartphones
- Voice search support

**For Customers**
- Search by skill and area
- View verified worker profiles with ratings
- Send job requests or contact directly via WhatsApp / call
- Post micro jobs (1-day or weekly)

**For Admins**
- Review uploaded work proofs
- Approve or reject workers
- Live dashboard with stats

---

## Tech

Pure HTML, CSS, JavaScript — one single file, no frameworks, no backend, no npm.

Loads fast on 2G/3G. Can be shared as a file over WhatsApp. Anyone can host it for under ₹500/year.
